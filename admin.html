Préparez l'ajout d'un film ou d'une série. GitHub demandera ensuite de vous connecter et de confirmer la demande. Seules les demandes de votre compte seront traitées.

Une fois la demande créée, GitHub Actions recherchera l'affiche et les informations sur TMDB. Une validation par GitHub est nécessaire : le bouton ne publie pas directement un film.
